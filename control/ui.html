Cursor CLI 接管
命令行版共用同一套桥接与模型
      展开时检测
    
    

      

      

        接管不会修改官方 Cursor CLI：包装器只注入 HTTPS_PROXY 与证书路径。
        
        
        
        
        
        
        
      

      

      
Cursor CLI 不读取 Cursor 的 settings.json，只能通过环境变量进入代理。安装包装器后会生成 cursor-agent-bridge：它先载入桥接写出的环境文件，再启动官方 cursor-agent。桥接断开时环境文件会被删除，包装器自动退回直连。首次使用建议先执行一次简短对话验证。CLI 首次运行会改写 ~/.cursor/cli-config.json 的默认模型，属正常行为，可用 /model 切回。

      
若后台被强制终止（SIGKILL、系统休眠被杀）而来不及删除环境文件，CLI 可能提示代理不可达：重新启动后台或删除 agent-env 即可恢复。
